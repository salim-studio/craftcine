# CraftCine pipeline (6 stages)

0. **Understand** — read the product/page (read-only). Pin down 3 features + audience + tone.
1. **Direct** — pick one of the 9 themes. Write a 5-line spec (type, colors, density).
2. **Map** — choose 6–10 shots from the 24. One shot = one motion = one message.
3. **Storyboard** — write `storyboard.json` (titles + durations + logo hold ≥ 1s).
4. **Execute** — `render --preview`, iterate, `still` every shot, then final `render`.
5. **Deliver** — `workbench`, plus with/without-BGM versions when audio exists, plus `draft` on request.

Pacing: distribute energy 1 → 5 → 1 (quiet / peak / breath). Hard cuts land on beats only.
