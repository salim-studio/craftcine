# Visual QA (quick check before delivery)

- R1 One shot = one motion. Same motion twice? Delete one.
- R2 Text readable on every background (stroke/contrast). No glow spam — one deliberate highlight at most.
- R3 The closing logo/message holds ≥ 1s. After every element batch, 0.5s of stillness.
- R4 Full-screen beat hits (flash/slam) ≤ 3 per film.
- R5 No sensitive data in frames (customers, keys, personal data) — sanitize first.
- R6 Every hard cut sits on a beat (≤ 3 frames of error on review).
